# Marketing Quiz Practice

A beginner-friendly Python practice repository containing small console-based projects created while learning Python fundamentals.

## 📌 About This Repository

This repository contains three practice projects:

1. **Rock Paper Scissors Game**
2. **Marketing Quiz**
3. **Number Guessing Game**

The projects were created to strengthen my understanding of Python programming through practical, interactive programs.

## 📂 Projects

### 1. Rock Paper Scissors

A console-based game where the user plays Rock Paper Scissors against the computer.

**Concepts practiced:**
- `while` loops
- `if`, `elif`, and `else` statements
- Lists and indexing
- The `random` module
- User input
- Counters and score tracking
- String methods such as `.lower()`

### 2. Marketing Quiz

A simple marketing quiz based on the **S-T-P marketing framework**:

- Segmentation
- Targeting
- Positioning

The program collects basic student details and displays a report card with the user's score and percentage.

**Concepts practiced:**
- User input
- Conditional statements
- Variables
- String methods
- Type conversion using `int()`
- Score calculation
- Basic formatted output

### 3. Number Guessing Game

A game in which the computer generates a random number and the user tries to guess it.

The program provides feedback about whether the guess is higher or lower than the generated number and tracks the number of attempts.

**Concepts practiced:**
- The `random` module
- `random.randint()`
- `while` loops
- Input validation using `.isdigit()`
- Type conversion
- Comparisons
- Attempt counting

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/MANOHAR2004/Marketing-quize.git
   ```

3. Open the project folder in VS Code or another code editor.
4. Run any Python file from the terminal:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of the Python file you want to run.
